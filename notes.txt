📌 Main Problems Found
Header used messy inline styles and wasn’t structured properly → items stacked instead of aligning.
Layout didn’t use flexbox → sidebar, content, and cards all stacked vertically.
Cards looked identical and weren’t responsive.
No mobile responsiveness (no media queries).
Class names were vague and confusing.
Sidebar, button, and data area had little to no styling.
Too much inline CSS → hard to maintain.


🛠️ How It Was Fixed
Rebuilt header using proper HTML + flexbox for clean alignment.
Used flexbox for layout → sidebar + content now side by side.
Cards now use flex-wrap → responsive and evenly spaced.
Gave each card a unique color for clarity.
Added media queries → layout works on mobile.
Removed inline styles → moved everything to CSS.
Improved class names (BEM-style) → clearer structure.
Sidebar converted to proper <ul>/<li> list.
Styled button and wrapped it in a container.


⚠️ JavaScript Bugs
var in loop caused closure issue → all data failed to render.
Errors were hidden (console.log only).
Wrong error syntax: throw err() instead of throw new Error().



💡 Improvements Made
Fixed bug using let / better loop handling.
Switched to async/await for cleaner code.
Added loading message for user feedback.
Displayed errors in UI (not just console).
Disabled button during loading to prevent spam clicks.
Used DocumentFragment for better performance.
Added proper API error checking (res.ok).
